PHAKAMA EASTERN CAPE - STATIC WEBSITE

Open index.html in any modern browser. No installation, server or build step is required.

Contents:
- index.html - page structure and organisation copy
- styles.css - desktop, tablet and mobile design
- script.js - navigation, mobile menu and back-to-top interactions
- assets/ - local logo, hero, event and news imagery
- pages/ - individual pages for every sidebar subcategory

All pages work locally. Open index.html and use the sidebar navigation to move between
About, Programme, News, Resource and Get Involved pages.

The layout is based on the supplied homepage screenshots and the two supplied homepage
content PDFs. The hero background is an original clean recreation of the photographed
community scene shown in the supplied screenshot. Event, news and logo imagery were
isolated from the supplied visual references.
